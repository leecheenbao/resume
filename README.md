# resume

個人履歷網站

## PDF 版本

專為 PDF 輸出的精簡獨立版本：

- **resume-pdf.html**：PDF 專用頁面（無導覽、篩選按鈕等互動元素）
- **pdf.css**：精簡樣式（白底、無陰影、正式排版）

### 使用方式

1. 從主頁點擊導覽列的「下載 PDF」，或直接開啟 `resume-pdf.html`
2. 按 **Cmd+P**（Mac）或 **Ctrl+P**（Windows）
3. 目的地選擇「另存為 PDF」
4. 儲存

## PDF 版本

專為產出 PDF 設計的獨立版本，精簡樣式、無多餘裝飾。

**使用方式：**
1. 點擊導覽列「下載 PDF」，或直接開啟 `resume-pdf.html`
